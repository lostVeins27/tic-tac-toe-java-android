# Tic-Tac-Toe-Java-Android
A simple Tic-Tac-Toe game uses Java code in android studio.

---

## Features ([x] = Implemented Already)
- [x]**Android GUI**: Interactive user-friendly simple design and functional android GUI interface.
- [x]**The Tic-Tac-Toe Game Board**: A GUI board contains 3x3 buttons that changes 'X' or 'O' whenever a player clicked on it.
- [x]**Changing Board Text Color**: Board text color changes based on the game state.
- [x]**Updating Text Label**: Change every time a player move or a player wins or a tie game.
- []**Versus AI**: To be implement before the release of prototype application. Player can choose a mode to go against an AI.

Even though some of the features are already implemented, we can still work on it to enchance it.
